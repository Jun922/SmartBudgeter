## 1. 🏗️ システムアーキテクチャ

### 1.1 構成概要

本アプリはフロントエンド・バックエンド・データベースの3層構成とする。

```
[ ユーザー ]
     ↓ HTTPS
[ フロントエンド ]  ← React
     ↓ REST API
[ バックエンド ]    ← Go
     ↓
[ データベース ]    ← PostgreSQL
```

### 1.2 技術スタック（案）

| レイヤー | 技術 | 備考 |
|---------|------|------|
| フロントエンド | React / TypeScript | レスポンシブ対応 |
| バックエンド | Go | REST API |
| データベース | PostgreSQL | クラウドホスティング |
| 認証 | JWT（JSON Web Token） | セッション管理 |
| ストレージ | クラウドストレージ | PDF出力ファイルの一時保存 |
| ホスティング | クラウド（AWS / GCP など） | HTTPS対応 |

## 5. 🔒 認証・セキュリティ設計

### 5.1 認証フロー

```
1. ユーザーがメールアドレス・パスワードを入力
2. バックエンドでパスワードのハッシュ検証
3. 認証成功時にJWTトークン（有効期限: 24時間）を発行
4. APIリクエスト毎にAuthorizationヘッダーへトークンを付与
5. バックエンドでトークンを検証してリソースアクセスを許可
```

### 5.2 セキュリティ対策

| 対策 | 内容 |
|------|------|
| パスワード | bcryptでハッシュ化（ソルト付き） |
| 通信 | HTTPS（TLS 1.2以上） |
| トークン | JWT、有効期限24時間 |
| データ分離 | user_id によるデータアクセス制御 |
| 入力検証 | サーバーサイドでのバリデーション実施 |

## 6. 🖨️ 帳票出力設計

### 6.1 PDF出力

| 項目 | 内容 |
|------|------|
| 出力単位 | 月次（対象年月を指定） |
| 含める内容 | 収支サマリー、カテゴリ別集計、収支一覧明細 |
| 生成方式 | サーバーサイドでPDF生成後、ダウンロード |
| ファイル名 | `家計簿_YYYY年MM月.pdf` |

### 6.2 CSVエクスポート

| 項目 | 内容 |
|------|------|
| 出力単位 | 任意期間（開始日・終了日を指定） |
| カラム構成 | 日付、種別、カテゴリ、金額、メモ |
| 文字コード | UTF-8（BOM付き、Excel対応） |
| ファイル名 | `家計簿_YYYYMMDD-YYYYMMDD.csv` |
