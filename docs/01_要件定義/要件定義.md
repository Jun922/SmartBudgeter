## 1. 🔭 プロジェクト概要

### 1.1 背景・目的

日々の支出・収入を手軽に記録・管理できる家計簿アプリを開発する。
ユーザーが家計の現状を可視化し、支出の傾向を把握することで、健全な家計管理を支援することを目的とする。

### 1.2 👥 対象ユーザー

- 個人の家計管理を行いたいユーザー
- 日々の収支を記録・把握したいユーザー

---

## 2. ⚙️ 機能要件

### 2.1 💰 収支管理機能

#### 2.1.1 収入・支出の登録
- 日付、金額、カテゴリ、メモを入力して収支を登録できる
- カテゴリは支出・収入それぞれで複数選択できる（例：食費、交通費、給与、副収入など）
- 登録した収支の編集・削除ができる

#### 2.1.2 🏷️ カテゴリ管理
- ユーザーが任意のカテゴリを追加・編集・削除できる

#### 2.1.3 📄 収支一覧の表示
- 日別・月別・年別で収支一覧を表示できる
- カテゴリや期間でフィルタリングできる

### 2.2 📊 ダッシュボード機能

- 当月の収入合計・支出合計・残高をサマリー表示する
- カテゴリ別支出の内訳をグラフ（円グラフ・棒グラフ）で表示する
- 直近の収支履歴をリスト表示する

### 2.3 🖨️ 帳票出力機能

- 月次収支レポートをPDF形式で出力できる
- 指定期間の収支データをCSV形式でエクスポートできる
- 出力内容にはカテゴリ別集計・合計金額を含む

---

## 3. 🛡️ 非機能要件

### 3.1 ⚡ パフォーマンス
- 画面の初期表示は3秒以内に完了すること
- データ登録・更新操作は1秒以内に応答すること

### 3.2 🔒 セキュリティ
- ユーザーデータは認証済みユーザーのみアクセス可能とする
- 通信はHTTPS（TLS）を使用する
- パスワードはハッシュ化して保存する

### 3.3 🎨 ユーザビリティ
- スマートフォン・タブレット・PCに対応したレスポンシブデザインとする
- 直感的に操作できるUIを提供する

### 3.4 ☁️ 可用性・信頼性
- データはクラウドに保存し、デバイスをまたいで利用できる

## 6. 🎯 スコープ

### 6.1 ✅ スコープ内（今回対応）

- 収入・支出の登録・編集・削除
- カテゴリ管理
- ダッシュボードでの収支サマリー・グラフ表示
- 月次レポートのPDF出力
- 収支データのCSVエクスポート

### 6.2 ❌ スコープ外（将来対応）

- 家族・複数人での共有機能

- プッシュ通知

- 対応ブラウザ: Chrome / Safari / Firefox 最新2バージョン

- 言語: 日本語のみ（初期リリース）
- データ保持期間: ユーザーが削除するまで無期限保持
